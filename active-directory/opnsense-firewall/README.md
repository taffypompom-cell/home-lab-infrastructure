# OPNsense Firewall Lab

## Setup
- Installed and configured OPNsense firewall
- Configured WAN, LAN and OPT1 interfaces
- Set up DHCP and DNS services

## Problem
Client received IP address but had no internet access.

## Solution
- Reviewed firewall rules
- Added rule to allow outbound traffic from OPT1 network
